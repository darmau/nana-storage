## 关闭人脸识别

人脸识别用的 InsightFace 模型权重**只允许非商业使用**（见仓库的 `NOTICE`），不受 AGPL 覆盖。不能接受这个条件时，在 Workers Builds 的构建变量里加：

```
NANA_FACES = off
```

- 容器镜像不下载人脸模型，处理时不做人脸识别，“人物”页保持为空，其他功能不受影响。
- 用[设备端处理](../../device/install/)的话，设备端也要用同样的值构建：`NANA_FACES=off docker compose up -d --build`。否则设备处理的照片有人脸，云端处理的没有。
- 关掉之前已经识别的人脸会保留；之后再打开，只有新处理的照片会识别人脸。

## D1 读复制

打开之后，接口的读查询会落到离你近的副本上，写入仍然走主库。应用用 D1 会话保证你总能读到自己刚写的数据。副本不额外收费，按同样的读写行数计费。

初始化时给了 API 令牌的话已经打开了；否则在后台打开：D1 › `nana-db` › 设置 › Enable Read Replication。

## 预算告警

Cloudflare 后台 › 账单 › 计费用量 › 预算告警：设几档，比如 $20、$50、$100。

告警只发通知、不会封顶。真正的硬上限是应用内的熔断（本月容器估算费用的月度上限，默认 $10），见[费用](../../costs/)。两者互补：应用只能算自己知道的项，账单告警覆盖全部。

## 同时运行的容器数

默认同时最多 4 个容器处理照片。大批量导入时可以在 设置 › 成本防护 里临时调高（最多 32 个，最长 7 天，到期自动回落）。调高只是更快，总的容器时间不变。
