那时的第一原则：**除了你本人，任何人都不能以任何方式拿到照片。**

## 两道门

1. **Cloudflare Access**：整个域名都在 Access 后面，只放行你一个邮箱，用邮箱验证码登录。没登录的请求到不了 Worker。
2. **Worker 再校验一次**：每个请求（包括 HTML、JS、CSS 这些静态资源）都要验证 Access 签发的 JWT：签名、受众（AUD）、邮箱必须是 `OWNER_EMAIL`。身份配置缺任何一项时拒绝所有请求。代码里没有任何跳过鉴权的开关、环境变量或调试路由。

## 照片字节

- R2 不开公开访问、不发预签名链接，所有字节都由 Worker 校验身份后流出。
- `workers.dev` 子域名和预览地址都关闭，只能通过你的域名访问。
- 照片响应只用 `Cache-Control: private`：可以存在你自己的浏览器里，不会进 Cloudflare 的 CDN 缓存或任何共享缓存。
- 没有 Service Worker，不会把照片缓存在设备上。

## 浏览器

- CSP 只允许同源资源；唯一的例外是地图底图（`tiles.openfreemap.org`），只放行图片和数据请求，不放行脚本。
- 写请求要带专门的请求头并且同源，防止跨站请求伪造。
- 上传时按文件头检查类型，拒绝 SVG、HTML 这类可能包含脚本的文件。

## 不防什么

- **你的设备被别人拿到**：已经登录的浏览器可以直接看照片（Access 会话 24 小时）。锁好你的电脑和手机。
- **你的邮箱被盗**：邮箱验证码登录意味着控制了邮箱就能登录。给邮箱开两步验证。也可以在 Zero Trust 里换成其他登录方式（比如 GitHub、Google）。
- **你的 Cloudflare 账号被盗**：账号的所有者能看到 R2 里的一切。给 Cloudflare 账号开两步验证。
- **设备端界面**：见[设备端的安全](../../device/security/)。
- **地图**：OpenFreeMap 能看到你浏览的地图范围和 IP，看不到照片。见[地图](../../guide/map/)。

## 照片元数据

照片原件原样保存（包括 EXIF 里的 GPS）。缩略图和预览去掉了除色彩配置之外的所有元数据。下载原件时拿到的是完整的原文件——如果要分享给别人，注意里面的位置信息。
