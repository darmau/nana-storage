## 需要知道的取舍

设备界面（`localhost:7878`）**没有自己的登录**。设备登录过相册之后，**能打开这台电脑 7878 端口的人都能浏览你的照片**。这是有意的取舍：

- 端口只绑定 `127.0.0.1`，同一网络里的其他设备访问不到。
- 校验 Host 头，防止别的网站通过 DNS 重绑定访问它。
- 写操作要带专门的请求头，别的网页不能替你发起上传。

所以：不要在和别人共用的电脑账号上开着设备端处理；不用的时候 `docker compose stop`。

## 它能做什么、不能做什么

- 用你自己的 Access 登录（`cloudflared`），和浏览器是同一个身份、同一套校验。服务器没有为它加服务令牌或任何第二种身份。
- 它在服务器上的专用接口只能**读被认领、还在运行的任务的输入文件**，只能**写这个任务当前计划里的派生文件**（路径带版本号，期间被改过就对不上）。
- 浏览和上传用的是和浏览器完全相同的接口。
- 看到的服务器队列只有计数，没有文件名。
- 原件只在处理期间放在容器的临时目录里，处理完就删除；容器重启时清空暂存目录。
