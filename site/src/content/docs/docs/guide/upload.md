## 怎么上传

- **顶栏的“上传”菜单**：选“上传文件…”或“上传文件夹…”。浏览器不能在同一个选择框里同时选文件和文件夹，所以分成两项。
- **拖进页面**：把文件或文件夹拖到任意页面上。
- **文件夹卡片的右键菜单**：直接上传到那个文件夹。

上传到哪里：在某个文件夹页面里，就上传到这个文件夹；在其他页面，都上传到根目录。选择或拖进来的**文件夹会按原来的目录结构**建子文件夹。

## 支持的格式

| 类型 | 格式 |
|---|---|
| 照片 | JPEG、HEIC / HEIF、PNG、WebP、AVIF、GIF、TIFF |
| RAW | DNG、CR2、CR3、NEF、ARW、RAF、ORF、RW2、PEF、SRW 等 |
| 视频 | MP4、MOV（H.264 / HEVC） |

上传时按**文件头**判断类型，扩展名对不上也没关系；不认识的格式（以及 SVG、HTML 这类可能包含脚本的文件）直接拒绝。单个文件最大 50 GB。

## 自动配对

- **Live Photo**：同名的 HEIC / JPEG + MOV（比如 `IMG_0001.HEIC` 和 `IMG_0001.MOV`）合并成一张 Live Photo。
- **RAW + JPEG**：同名的 RAW 和 JPEG 合并成一张，JPEG 用来显示，RAW 作为附件保存，下载原件时一起下载。

## 去重

浏览器在本地算出每个文件的 SHA-256，**和资料库里已有的文件完全相同**的直接跳过，不会上传第二遍。

内容相似但不完全相同的（比如同一张照片的不同导出版本）会上传，之后可以在[重复照片](../similar/)里处理。

## 上传过程

- 文件按 20 MB 分块上传，某一块失败会自动重试；同时最多读 2 个本地文件。
- 本地文件 60 秒读不到数据（比如 NAS 或网络盘断开）时，整个队列暂停，等你点“继续”。
- 上传面板会估算这一批要花多少容器费用；照片很多时会建议改用[设备端处理](../../device/install/)。
- 上传期间不用刷新页面，处理好的照片会自己出现在列表里。处理进度在 设置 › 后台处理。

## 上传中断了

上传了一半就关掉页面、断网时，超过 1 小时还没传完的条目算作“上传中断”，对应文件夹的页面会列出这些文件名。**重新上传这些文件就行**：不算重复，旧的半成品会被替换掉。

## 从 iPhone / Mac 导出原件

- **iPhone 上的 Safari** 只能上传静态图片（系统给网页的是转成 JPEG 的副本，没有 Live Photo 的视频部分）。
- 想保留 Live Photo、HEIC 原件和完整的元数据：在 **Mac 的「照片」** 里选中照片 › 文件 › 导出 › **导出未修改的原件**，再把导出的文件夹拖进那时。
- 从 Google 相册迁移：用 Google Takeout 导出后上传照片文件即可。Takeout 附带的 JSON 元数据不会被读取。
