新照片处理时会自动检测人脸，同一个人出现在至少 3 张照片里之后，就会出现在 探索 › 人物 里。交互和 iOS 相册、Google 相册类似：一个“人物”就是同一个人的一组脸，名字可以留空。

:::caution[许可]
人脸识别用的 InsightFace 模型权重只允许**非商业使用**。不能接受时可以在部署时关闭（`NANA_FACES=off`），见[可选配置](../../deploy/options/)。
:::

## 命名与合并

- 人物页点“添加名字”。
- 起了一个已经存在的名字时，会问是不是同一个人，确认后合并。
- 也可以在人物页的菜单里“与其他人物合并”。
- 不想在列表里看到的人物可以隐藏（照片不受影响），常看的加入个人收藏（排在前面）。
- 封面：在人物页的照片上右键 › 设为人物封面，或者在查看器信息面板里点一张脸设为封面。

## 认错了怎么办

- **这不是 X**：在人物页选中认错的照片，点“这不是 X”。这些脸会重新识别，**不会再归回 X**，通常会直接归到本来该是的那个人。
- **这是其他人物…**：选中照片，直接指定给另一个人物（或者新建一个）。手动指定的永远优先，自动识别不会改掉。
- 在查看器的信息面板里点某张脸，也可以查看、改成其他人、标记“这不是 X”。

## 确认更多照片

人物页的“确认更多照片”会找出可能是这个人、但还没归进来的脸，一次一张问你“这是 X 吗？”。

## 按人物筛选文件夹

文件夹页面顶部显示这个文件夹里出现的人物，点头像只看有这个人的照片。

## 哪些脸不会被识别

- 太小（不到 36 像素）或者置信度低的脸只记录，不归入人物。
- 被[打码](../edit/)盖住的脸。
- 视频里的脸。

## 隐私

人脸检测和识别都在你自己的处理容器（或你自己的电脑）里完成，人脸向量和人名只存在你的 D1 和 Vectorize 里，不调用任何外部服务。日志里不记人名。
