那时支持 PWA，可以添加到手机主屏幕或电脑的程序坞，用独立窗口打开。

- **iPhone / iPad**：Safari 打开相册 › 分享 › 添加到主屏幕。
- **Android**：Chrome 菜单 › 添加到主屏幕 / 安装应用。
- **电脑**：Chrome / Edge 地址栏右侧的安装图标。

独立窗口里：

- 页面在顶部时**下拉刷新**。
- 断网或登录过期时顶部会出现提示，可以重新加载。
- 手机上底部是标签栏：照片、相册、探索、文件夹、资料库。

没有 Service Worker，不会把任何照片缓存在设备上；照片只用浏览器的私有缓存。
