### 每个月到底要花多少钱？

照片都处理好之后，几千张基本就是 Workers Paid 的 $5；5 万张大约 $8–9（主要是 R2 存储）。处理照片的费用只在上传时产生一次。详见[费用](../../costs/)。

### 会不会突然收到一大笔账单？

应用在结构上避免了所有会自己无限运行的东西，并且本月容器费用到了上限（默认 $10）就自动暂停。此外建议在 Cloudflare 账单里设预算告警。见[费用 › 月度上限](../../costs/#月度上限熔断)。

### 可以给家人开账号吗？

不能。那时只给一个人用。可以给每个人各自部署一份（各自的 Cloudflare 账号，或者同一个账号下不同的 Worker 名字——后者需要改仓库，不推荐）。

### Cloudflare 能看到我的照片吗？

照片存在你的 Cloudflare 账号里，和任何云存储一样，服务商在技术上有访问能力。那时保证的是“除了你和你的云服务商，没有任何第三方能拿到照片”：没有公开链接、不进 CDN 缓存、没有外部服务。

### 原件会被压缩或修改吗？

不会。原件原样保存在 R2 里，编辑只改缩略图和预览。

### 支持哪些格式？

JPEG、HEIC、PNG、WebP、AVIF、GIF、TIFF、主流 RAW 格式、MP4 / MOV。见[上传](../../guide/upload/#支持的格式)。

### 能用自己的电脑处理照片、不花容器费吗？

能，见[设备端处理](../../device/install/)。

### 人脸识别可以商用吗？

用的 InsightFace 模型权重只允许非商业使用。可以在部署时关闭人脸识别，见[可选配置](../../deploy/options/)。代码本身是 AGPL-3.0。

### 怎么更新？

在 GitHub 上点 Sync fork，或者启用自动同步。见[更新](../../deploy/updating/)。

### 为什么叫“那时”？

那时候的照片。
