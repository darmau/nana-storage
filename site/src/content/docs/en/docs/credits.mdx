## Software and models

Nana's code is open source under [AGPL-3.0](https://github.com/darmau/nana-storage/blob/main/LICENSE). The components below are downloaded at build time and keep their own licenses (full list in the repository's [NOTICE](https://github.com/darmau/nana-storage/blob/main/NOTICE)):

- **InsightFace buffalo_l** (SCRFD face detection, ArcFace recognition), ONNX export by Immich. The model weights are for **non-commercial research only**; `NANA_FACES=off` leaves them out entirely.
- **OpenAI CLIP ViT-B/32** image encoder, int8 ONNX export by Xenova, MIT License.
- **libvips, libheif, LibRaw, ExifTool, FFmpeg** for images and video.
- **ONNX Runtime** to run the models in the container.
- **Hono, React, TanStack, MapLibre GL** for the Worker and frontend.
- This website is built with **Astro** and **Starlight**.
